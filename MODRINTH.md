# BrassUi

**A complete Minecraft UI toolkit** — a 90+ widget Elementa kit in the Brassworks launcher idiom, a
built-in networking module, a node editor, and dev tools, all in one dependency.

## What you get

- **Widgets, not boilerplate** — buttons, toggles, sliders, dropdowns, text inputs, tables, virtual
  lists, charts, popups, modals, command palettes and more, all themed, animated and keyboard-aware
  out of the box. 89 widgets ship in the kit; each is a normal Kotlin class you can extend.
- **Theming that is a role, not a value** — nine built-in themes and role-based colours, so a theme
  swap re-skins your whole UI live.
- **A real layout system** — boxes, flows, grids, forms, scroll areas, split panes, breakpoints and
  virtual lists, built on Elementa constraints.
- **Text, done properly** — markdown, syntax-highlighted code, fuzzy search, tags, time-ago, and a
  full text editor stack.
- **Node editor** — a Blender-style node graph with undo/redo, BSON native persistence (JSON export) and a plugin API.
- **Networking, baked in** — declare an action once and get automatic registration, permissions,
  per-player rate limiting, validation, server-pushed state, optimistic updates and translated
  errors. No boilerplate, no manual registration.
- **Dev tools** — an in-game inspector (Ctrl+Shift+D) and a capture pipeline for documentation.
- **Game content, the safe way** — items, entities, block models and player heads are drawn through a
  platform seam; the toolkit itself stays loader- and version-agnostic.

## Multi-platform

One jar works on both client and dedicated server. The same toolkit powers a standalone desktop
gallery app, so UI code you write once runs in-game and off-game.

## Requirements

- NeoForge 21.1.x / Minecraft 1.21.1
- [Kotlin For Forge](https://modrinth.com/mod/kotlinforforge) (declared as a dependency automatically)
