# Widget screenshots

Drop a PNG named after each widget here and it appears on that widget's page automatically.

- File name: `<WidgetName>.png` - e.g. `BrassButton.png`, `BrassPanel.png`.
- Until a file exists, the widget page shows a labelled placeholder with the exact path to add.
- Pixel art renders sharp - the pages display screenshots with `image-rendering: pixelated`.

Capture from the in-game gallery (`/brassui`), 16:10-ish framing works best.
